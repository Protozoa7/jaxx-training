# Jaxx Training Site

A standalone, mobile-first four-day workout website.

## Files

- `index.html`
- `styles.css`
- `script.js`

No frameworks, package managers, or external libraries are required.

## Run locally

Open `index.html` in any modern web browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the three site files from this folder.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save.

GitHub will provide the public site address after deployment.

## Workout Split

### Day 1 — Deadlift
- Conventional Deadlift only
- 4 × 3–6

### Day 2 — Upper
- Lat Pull Down — 3 × 8–12
- Cable Rows — 3 × 8–12
- Pull Over Machine — 3 × 10–15
- Hammer Curls — 3 × 10–15
- Cable Crunches — 3 × 12–20

### Day 3 — Lower
- Standing Squat Machine — 3 × 8–12
- Sitting Squat Machine — 3 × 10–15
- Lunges — 3 × 8–12 per leg
- Goblet Squats — 3 × 10–15

### Day 4 — Combo
- Goblet Squats — 3 × 8–12
- Lat Pull Down — 3 × 8–12
- Lunges — 3 × 8–12 per leg
- Cable Rows — 3 × 10–15
- Hammer Curls — 3 × 10–15
- Cable Crunches — 3 × 12–20
